# 📸 Project Overview

> **BAKI MODE** is an anime-inspired fitness tracker built using **Flask + HTML + CSS + JavaScript + SQLite + ExerciseDB API**.

Track every workout, calculate BMI, monitor weekly progress, and train with a **Baki Hanma inspired UI**.

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/vanamalajayasurya/Fitness-Tracker.git
cd Fitness-Tracker
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Project

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

# 🌐 API Endpoints

## Workout APIs

| Method | Endpoint         |
| ------ | ---------------- |
| GET    | `/muscle-groups` |
| GET    | `/workouts`      |
| POST   | `/workouts`      |
| DELETE | `/workouts/<id>` |
| GET    | `/stats`         |

## BMI APIs

| Method | Endpoint       |
| ------ | -------------- |
| POST   | `/bmi`         |
| GET    | `/bmi/history` |

## Exercise APIs

| Method | Endpoint                       |
| ------ | ------------------------------ |
| GET    | `/exercises`                   |
| GET    | `/exercise/search?name=`       |
| GET    | `/exercise/bodypart?bodyPart=` |
